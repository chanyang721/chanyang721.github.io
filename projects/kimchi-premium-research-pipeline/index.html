Ownership

직접 담당한 범위

  • 김치프리미엄 변동폭을 이용한 임계값 전략 가설과 실험 절차 문서화
  • 2021–2024 시간 단위 환율·BTC·USDT 가격 데이터 정제와 김치프리미엄(KPR) 산식 검증
  • 매수·매도 기준값 조합별 손익 계산, 히트맵 생성, 위험·손실 대비 수익성과 단순 보유 전략 비교
  • Yahoo Finance·Bithumb 데이터를 이용한 1시간 단위 가격 갱신과 Google Drive 적재 자동화
  • 전략별 자금, 지갑, 주문, 체결 상태를 분리한 Excel 기반 거래 로그 구조 구현

Constraints

먼저 해결해야 했던 제약

  • 같은 전략도 검증 기간에 따라 유리한 임계값이 달라 단일 결과를 일반화할 수 없었습니다.
  • 가격 데이터의 시간대와 결측 구간을 맞추고, 기존 김치프리미엄 산식과 단순화한 산식의 결과를 대조해야 했습니다.
  • 백테스트 수익률과 실제 체결 결과는 수수료, 슬리피지, 유동성, 부분 체결 때문에 달라질 수 있었습니다.
  • 프로젝트 중단으로 실제 주문 자동화는 완료하지 못해 연구·프로토타입 범위와 운영 성과를 분리해야 했습니다.

Implementation Timeline

가설 검증에서 반복 가능한 데이터 갱신까지 확장했습니다

각 단계는 독립된 작업이 아닙니다. Phase 01의 매수·매도 기준값과 Phase 02의 현재 김치프리미엄이 Phase 03으로 넘어가 거래 신호와 전략별 상태 기록에서 합쳐집니다. 필요한 Phase를 선택하면 해당 단계에서 어떤 문제를 보고 어떤 구조와 검증 기준으로 이어졌는지 확인할 수 있습니다.

Phase 01 · 임계값 백테스트

임계값 백테스트

Phase 01

가상 거래로 임계값 후보를 고르고 전략 설정값으로 넘겼습니다

김치프리미엄이 낮은 기준을 하향 돌파하면 USDT를 사고, 높은 기준을 상향 돌파하면 파는 규칙을 두었습니다. 매수·매도 기준을 0.5 단위로 바꾸며 거래 수수료 0.2%를 반영한 결과를 계산했습니다.

  1. 01

    데이터 정렬

    USD/KRW, BTC/USDT, BTC/KRW의 시간 단위를 맞추고 주말 결측 구간을 보정해 2021–2024 검증 데이터를 구성했습니다.

  2. 02

    조합 탐색

    매수 기준이 매도 기준보다 낮은 조합만 실행하고, 각 조합의 거래 횟수와 누적 손익을 계산해 히트맵으로 비교했습니다.

  3. 03

    결과 비교

    KRW·USDT 가상 잔액과 매 시점 평가자산을 갱신해 거래별·누적 손익을 계산하고, 위험 대비 수익률·손실 대비 이익·단순 보유 수익률과 함께 비교했습니다.

다음 단계로 넘긴 값과 해석 한계

히트맵에서 검토한 단기·장기 매수·매도 기준값을 전략 A/B 설정으로 넘겼습니다. 다만 2024년 조건 선택 구간과 2021–2024 재검증 구간이 겹치므로 기간을 완전히 분리한 독립 검증은 아닙니다. 특정 수익률이나 최적값은 대표 성과로 내세우지 않습니다.

Outcome

확인 가능한 결과

  • 시간 단위 가격 데이터에서 임계값 조합별 손익과 비교 지표를 계산하는 백테스트 구현
  • 수익률 히트맵과 단순 보유 수익률 비교로 전략 조건을 검토할 수 있는 결과 리포트 구성
  • 1시간 단위 가격 수집, 기존 데이터 병합, 로컬·Google Drive 적재 자동화
  • 전략별 지갑·자금·주문·체결 로그 스키마와 거래소 응답 매핑 구현

Limitations

한계와 미구현 범위

  • 백테스트 구간과 전략 조건 선택 구간을 완전히 분리한 독립 검증은 아닙니다.
  • 문서와 실험 산출물에 임계값 표기가 일부 달라 정확한 최적값을 대표 성과로 사용하지 않습니다.
  • 실제 주문 자동화와 부분 체결·거래소 장애 복구는 프로젝트 중단으로 완료하지 못했습니다.
  • 갱신 상태는 1시간마다 확인했지만 환율 데이터 제공 시간의 공백까지 자동 보정하지는 못했습니다.
  • 백테스트 수익률은 실제 투자 성과나 무위험 차익거래 결과로 해석하지 않습니다.
